# TX9_WT benchmark dataset (in-house HEK293, WT/DMSO)

Processed per-codon ribosome-profiling data for the in-house **TX9_WT** dataset
(HEK293, wild-type, DMSO control; biological replicates rep3 + rep4, replicate-averaged),
packaged so that peers can reproduce the headline gene-level benchmark (Table 1 / Figure 1)
exactly, using only this repository.

## Scope

This release contains the **benchmark universe**: the gene-longest, high-coverage
(`T_high`) transcripts used for the paper's gene-level 5-fold cross-validation
(**3,257 transcripts / 3,250 genes**; 3,101 are scoreable and enter the reported metrics,
matching the paper). It is sufficient to reproduce the TX9_WT columns of the headline
benchmark. The full transcriptome (for the coverage-filter derivation), the per-replicate
raw counts (for the reliability-crossover analysis), and the natively low-coverage
transcripts are **not** included here; the raw sequencing data will be deposited in GEO
upon publication.

## Files

| file | description |
|---|---|
| `tx9_wt_benchmark.npz` | per-transcript data (6.3 MB), one key per transcript id (`ENST…`). Load with `numpy.load(path, allow_pickle=True)`; `z[tid].item()` returns the record below. |
| `tx9_wt_benchmark_index.csv` | human-readable index (3,257 rows): `transcript_id, gene_id, n_codons, cds_start, cds_end, sum_avg_count, sum_avg_count_norm, cv5_test_fold`. |

### Record schema (`z[tid].item()`)

```python
{
  "5utr": {"sequence": "<5'UTR nucleotides>"},          # for the optional magnitude head
  "cds": {
     "sequence":       "<CDS nucleotides, length 3L>",   # GENCODE v47
     "avg_count":      [float, ... length L],            # per-codon P-site counts, averaged over rep3+rep4
     "avg_count_norm": [float, ... length L],            # per-file-normalised counts (T_high uses sum > 0.5)
     "start": int, "end": int                            # CDS coordinates
  }
}
```

The training target used in the paper is the covered-mean-normalised `log(1+mu)`
(`covmean0_log`): `mu_i = avg_count_i / mean(avg_count over covered codons)`, then `log1p`.
This transform is implemented in `ribopipe` (`--target covmean0_log`); ship raw `avg_count`
and let the code normalise, so nothing is hidden in preprocessing.

## Reproduce the headline TX9_WT benchmark

```bash
ribopipe cv5 \
  --npz        data/TX9_WT/tx9_wt_benchmark.npz \
  --enst2ensg  reproduce/enst2ensg_grch38.json.gz \
  --folds      reproduce/folds/cv5_folds_TX9_WT.json \
  --methods    codon_mean,ribopipe \
  --out-json   tx9_cv5.json
```

Verified: `codon_mean` gives per-transcript Pearson **P = 0.1629 ± 0.0068** with
`n_per_fold = [616, 619, 626, 621, 619]` (sum 3,101), and RiboPipe reproduces the paper's
headline TX9_WT value, identical to the canonical harness.
